# Mini-Projet : Analyse Multivariée – Bank Marketing

## Présentation

Ce projet porte sur l'analyse multivariée d'un jeu de données de marketing bancaire. Il vise à étudier les caractéristiques des clients et à identifier les facteurs associés à la souscription d'un dépôt à terme.

## Objectifs

- Préparer et explorer les données.
- Réaliser une Analyse en Composantes Principales (ACP).
- Effectuer une Analyse des Correspondances Multiples (ACM), selon la nature des variables.
- Appliquer des méthodes de classification.
- Combiner les résultats statistiques pour identifier des profils de clients.
- Interpréter les résultats dans le contexte du marketing bancaire.

## Technologies utilisées

- R
- RStudio
- R Markdown
- Analyse statistique multivariée
- Visualisation de données

## Structure du projet

- `02_preparation.R` : préparation des données.
- `03_acp.R` : Analyse en Composantes Principales.
- `03_bis_acm.R` : Analyse des Correspondances Multiples.
- `04_classification.R` : classification des observations.
- `05_analyse_combinée.R` : analyse combinée des résultats.
- `rapport_projet.Rmd` : rapport détaillé du projet.

## Exécution

1. Ouvrir le projet dans RStudio.
2. Installer les packages R nécessaires.
3. Vérifier le chemin d'accès aux données.
4. Exécuter les scripts dans l'ordre adapté à leurs dépendances.
5. Compiler `rapport_projet.Rmd` en HTML avec R Markdown.

## Résultats

Les résultats, visualisations et interprétations seront présentés dans le rapport final.
